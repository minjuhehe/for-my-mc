Lost Sky

เมืองลอยฟ้าโบราณพังทลายลงสู่ความว่างเปล่า วันนี้ซากของมันกำลังลอยกลับขึ้นมา เริ่มจากเกาะเล็ก ๆ ของคุณเอง ออกสำรวจซากปรักหักพัง แล้วนำโบราณวัตถุกลับมาฟื้นฟู Sky Citadel ร่วมกับผู้เล่นทั้งเซิร์ฟ

ที่อยู่เซิร์ฟเวอร์ รอประกาศ
ยังไม่มี IP สำหรับเข้าเล่น จะประกาศบนหน้านี้เมื่อทดสอบระบบเกมครบและเจ้าของเซิร์ฟยืนยันแล้ว ช่องทางติดต่อ (เช่น Discord) ก็รอประกาศเช่นกัน
อ่านเรื่องราว ดูวิธีเริ่มเล่น
สถานะตอนนี้

อะไรพร้อมแล้ว อะไรยังเป็นแผน

Lost Sky ยังอยู่ระหว่างพัฒนา ระบบเกมยังไม่ได้ทดสอบครบ ข้อมูลในหน้านี้มาจากเอกสารออกแบบ และอาจเปลี่ยนก่อนเปิดจริง

ตัดสินใจแล้ว

  • ยืนยันแล้ว แนวเกม Skyblock ที่มีเนื้อเรื่อง 5 บท ฟื้นฟู Sky Citadel ด้วยโบราณวัตถุ
  • ยืนยันแล้ว เว็บนี้ใช้แนะนำเซิร์ฟเท่านั้น ไม่มีระบบสมัครสมาชิก ไม่มีร้านเติมเงิน

ทำแล้ว แต่ยังไม่ได้ทดสอบ

  • ร่าง · ยังไม่ทดสอบ สคริปต์เนื้อเรื่อง: บท, การบริจาคโบราณวัตถุ, วาร์ป Citadel, ซากปรักหักพัง และฉายา
  • แผนช่วงทดสอบ ทีมละ 4 คน, ปิด PvP, Java Edition, เข้าเล่นด้วย whitelist

ยังรอประกาศ

  • รอประกาศ ที่อยู่เซิร์ฟเวอร์และช่องทางติดต่อ
  • รอประกาศ วันเปิด และความยาวของแต่ละซีซัน
  • รอประกาศ จะรองรับ Bedrock (มือถือ, คอนโซล) หรือไม่
ยืนยันแล้ว ตัดสินใจแล้ว ร่าง เขียนแล้ว ยังไม่ทดสอบในเกม แผน ตั้งใจไว้ อาจเปลี่ยน รอประกาศ ยังไม่มีข้อมูล

วิธีเริ่มเล่น

เตรียมตัวก่อนเซิร์ฟเปิด

ไม่ต้องลงม็อดหรือดาวน์โหลดอะไรจากเรา ใช้ Minecraft ปกติได้เลย

  1. มี Minecraft: Java Editionเล่นบน PC, Mac หรือ Linux ช่วงทดสอบวางแผนรองรับ Java เท่านั้น
  2. รอประกาศที่อยู่เซิร์ฟเวอร์ตอนนี้ยังไม่มี IP สำหรับเข้าเล่น จะประกาศบนหน้านี้
  3. ขอเข้า whitelistส่งชื่อผู้เล่น Minecraft ให้ทีมงานผ่านช่องทางที่จะประกาศพร้อมกับที่อยู่เซิร์ฟ
  4. เพิ่มเซิร์ฟในเกมMultiplayer → Add Server → ใส่ที่อยู่ที่ประกาศ → Done
  5. พิมพ์ /is เพื่อสร้างเกาะจากนั้นพิมพ์ /chapter เพื่อดูว่าเนื้อเรื่องไปถึงบทไหนแล้ว

เรื่องราว

ห้าบทสู่ Sky Citadel

นานมาแล้ว มีอารยธรรมหนึ่งอาศัยอยู่บนท้องฟ้ารอบป้อมปราการใหญ่ชื่อ Sky Citadel วันหนึ่งทุกอย่างแตกออกเป็นเสี่ยงและร่วงหล่นสู่ความว่างเปล่า

บัดนี้ชิ้นส่วนของมันกำลังลอยกลับขึ้นมา คุณตื่นขึ้นบนเกาะเล็ก ๆ ข้างซากป้อม ค้นหาโบราณวัตถุ นำกลับมาคืน และปลุก Citadel ให้ฟื้นคืนชีพอีกครั้ง

แต่ละบทจะปลดล็อกให้ทุกคนพร้อมกัน เมื่อแต้มโบราณวัตถุที่ผู้เล่นทั้งเซิร์ฟบริจาครวมกันถึงเป้าหมาย ตัวเลขเป้าหมายเป็นค่าเบื้องต้น และอาจปรับตามจำนวนผู้เล่น

Chapter 1 · The Awakening

บทที่ 1 การตื่นขึ้น

เป้าหมายเริ่มต้นแผน

ทุกคนเริ่มบนเกาะเล็ก ๆ ของตัวเอง ซากป้อมยังเงียบสงบ

  • เกาะพื้นฐาน
  • เครื่องปั่นหิน (cobblestone generator)
  • ซากปรักหักพังระดับ 1
Chapter 2 · Roots of Stone

บทที่ 2 รากแห่งศิลา

เป้าหมาย100แต้มตัวเลขเบื้องต้น

รากหินโบราณเริ่มงอกกลับเข้าหาเกาะ นำแร่และผืนดินใหม่มาด้วย

  • เครื่องปั่นแร่ระดับ 2
  • ไบโอมป่าและทุ่งหญ้าบนเกาะ
  • ซากปรักหักพังระดับ 2
Chapter 3 · The Drowned Spire

บทที่ 3 หอคอยใต้น้ำ

เป้าหมาย300แต้มตัวเลขเบื้องต้น

ยอดหอคอยที่จมอยู่ใต้ทะเลเมฆโผล่ขึ้นมา พร้อมความลับของมหาสมุทรลอยฟ้า

  • ไบโอมมหาสมุทร
  • โบราณวัตถุจากการตกปลา
  • อัปเกรดขนาดเกาะ +1
  • ซากปรักหักพังระดับ 3
Chapter 4 · Ember Halls

บทที่ 4 โถงถ่านเพลิง

เป้าหมาย600แต้มตัวเลขเบื้องต้น

โถงใต้ป้อมที่ยังคุกรุ่นด้วยไฟเก่าถูกเปิดออก ผู้พิทักษ์ตัวแรกกำลังรออยู่

  • ไบโอม Nether
  • เครื่องปั่นลาวาและ blaze
  • ซากปรักหักพังระดับ 4 มีมินิบอส
Chapter 5 · The Citadel Rises

บทที่ 5 Citadel คืนชีพ

เป้าหมาย1000แต้มตัวเลขเบื้องต้น

Sky Citadel ลอยขึ้นอีกครั้ง ศึกสุดท้ายจะตัดสินว่าท้องฟ้าจะกลับมาสงบหรือไม่

  • ไบโอมท้องฟ้าแบบ End
  • คราฟต์ปีก elytra ได้
  • บอสใหญ่ประจำซีซัน

ตามแบบที่วางไว้ เมื่อบอสบทที่ 5 ถูกปราบ ซีซันจะจบลง เกาะจะรีเซ็ต แต่ฉายาและของตกแต่งยังอยู่ ความยาวของซีซันยังไม่ได้กำหนด

กฎ

ช่วยกันรักษาท้องฟ้าให้น่าอยู่

กฎเบื้องต้น อาจเพิ่มเติมก่อนเปิดเซิร์ฟ

  • ห้ามแกล้งทำลายหรือขโมยเกาะมีระบบป้องกัน และมีบันทึกการวางและทุบบล็อกไว้ตรวจสอบ
  • แบ่งกันใช้ซากปรักหักพังห้ามปิดทางเข้า ห้ามดักผู้เล่นอื่น ห้ามทำลายปริศนา
  • ห้ามโกงหรือใช้บั๊กถ้าเจอบั๊กหรือวิธี dupe ของ ให้แจ้งทีมงาน
  • ไม่มี PvPตามแผนช่วงทดสอบ PvP ปิดทุกพื้นที่ รวมถึงในซากปรักหักพัง
  • สุภาพในแชตห้ามพูดจาเกลียดชัง สแปม หรือโฆษณา
  • หนึ่งคนหนึ่งบัญชีห้ามใช้บัญชีสำรองฟาร์มโบราณวัตถุ

คำถามที่พบบ่อย

ถาม-ตอบ

เซิร์ฟเปิดให้เล่นเมื่อไหร่

ยังไม่มีกำหนด ระบบเกมยังทดสอบไม่ครบ เมื่อพร้อมจะประกาศวันเปิดบนหน้านี้

IP หรือที่อยู่เซิร์ฟเวอร์คืออะไร

ยังไม่ประกาศ จะแสดงในส่วน "ที่อยู่เซิร์ฟเวอร์" ด้านบนเมื่อเจ้าของเซิร์ฟยืนยันแล้ว

เล่นบนมือถือหรือคอนโซล (Bedrock) ได้ไหม

ยังไม่ได้ตัดสินใจ แผนช่วงทดสอบรองรับเฉพาะ Java Edition

ต้องลงม็อดไหม

ไม่ต้อง ใช้ Minecraft ปกติได้เลย ม็อดเพิ่มความลื่นหรือ shader ใช้ได้ตามแผน แต่ห้ามโปรแกรมโกงทุกชนิด

เล่นกับเพื่อนได้กี่คน

แผนตอนนี้คือสูงสุด 4 คนต่อเกาะ ใช้คำสั่ง /is team invite เพื่อชวนเพื่อน

มี PvP ไหม

ตามแผนช่วงทดสอบ PvP ปิดทุกพื้นที่

มีเติมเงิน, VIP หรือระบบสมาชิกไหม

ไม่มี เว็บนี้ใช้แนะนำเซิร์ฟอย่างเดียว ไม่มีระบบสมัครสมาชิกหรือร้านค้า

ตัวเลขแต้มในแต่ละบทจะเปลี่ยนไหม

อาจเปลี่ยน ตัวเลขตอนนี้เป็นค่าเบื้องต้น จะปรับให้เหมาะกับจำนวนผู้เล่นจริง

จบซีซันแล้วเกิดอะไรขึ้น

ตามแบบที่วางไว้ เมื่อบอสบทที่ 5 ถูกปราบ ซีซันจะจบ เกาะรีเซ็ต แต่ฉายาและของตกแต่งยังอยู่ ความยาวซีซันยังไม่ได้กำหนด

Lost Sky เป็นเซิร์ฟเวอร์ Minecraft ที่ทำโดยแฟน ไม่เกี่ยวข้องกับ Mojang หรือ Microsoft

ข้อมูลอ้างอิงจากเอกสารออกแบบของโปรเจกต์ · อัปเดตหน้านี้ล่าสุด 29 กันยายน 2026
