# Rules for working on this repo

This is the design draft for the "Lost Sky" Skyblock Minecraft server.

After **every** addition or change:
1. Add an entry to `CHANGELOG.md` (what, why, commands touched).
2. Update `docs/COMMANDS.md` if any command or permission changed.
3. Update `docs/DEV_NOTES.md` if it changes how systems connect or adds saved variables.
4. Tell the owner in plain words what was added and which commands changed.
